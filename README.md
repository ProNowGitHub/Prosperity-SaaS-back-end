# Prosperity SaaS – Backend

Express API, deployed to Render on every push to `main`.

```bash
npm install
npm start       # http://localhost:3000
```

Endpoints: `GET /health`, `GET /api/hello`

`CORS_ORIGIN` (comma-separated) restricts which frontends may call the API; defaults to `*`.
Frontend repo: https://github.com/ProNowGitHub/Prosperity-SaaS-front-end
